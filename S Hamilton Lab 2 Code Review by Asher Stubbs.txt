S Hamilton Lab 2 Code Review
By Asher Stubbs
The GUI for this lab is easy to use and well laid out, though I would have liked the sort by labels to align with the button edges. The use of double for the total, highest, and lowest population variables is not technically necessary, but has no real downside beside a negligible memory use increase. I did get some crashes because of a lack of data validation on record adding/editing, that is something I overlooked in my own code also. I would have liked the highest and lowest population numbers to be tied to a city name or city ID so data lookup based on those numbers could be easier. Try/catches are used in the population get methods to handle null values if the get queries fail. Overall the lab satisfies the requirements and I believe is only really lacking data validation or exception handling in the database editing functions.
